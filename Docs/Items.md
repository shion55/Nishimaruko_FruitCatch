# 落下物の仕様

## 取得と弾き上げ

- 口が開いている間は、落下物の幅に関係なく口への接触で取得する。閉口時は取得・弾き上げを行わない。
- 口の左右のさらに外側に救済用の判定を置く。通常時は、口には触れず、この判定だけに触れた果物を消費せず真上へ弾き上げる。
- フィーバー中は弾き上げを行わず、左右の救済用範囲でも落下物を取得する。虫も拡大した取得範囲では減点対象になる。口を閉じている間は取得しない。
- 口と救済用の判定へ同時に触れた場合は取得を優先する。
- 弾き上げは果物1個につき何回でも行う。上昇中は再び弾かず、下降後に外側へ触れると弾き直す。
- 上昇中も口へ触れれば取得できる。音程による減速は上昇中には適用せず、下降すると通常の音程制御へ戻る。
- 弾き上げによる横移動はない。画面下へ落ちた落下物は削除する。
- 虫は取得すると減点だけを行い、弾き上げは行わない。通常時は外側の救済用判定では取得しない。

Eaterの口判定は横向きカプセル。声量で横幅だけを変え、声量では高さを変えない。フィーバー中はEater全体の拡大に合わせて判定も縦横に広がる。左右の救済用判定は口より下に置き、開口に合わせて外側へ広がる。声量による口幅の変化は、取得できる横方向の範囲に影響する。得点と食後効果は取得時に一度だけ発生する。

果物を食べると口を約0.12秒だけ閉じたスプライトに切り替える。入力による開閉と取得判定は継続し、連続して食べた場合は最後の取得から閉口時間を数え直す。虫ではこの閉口の演出を出さない。

閉口時間はEaterの`Eating Close Duration`で調整する。

## 種類

| 落下物 | 得点 | 食後の効果 |
| --- | --- | --- |
| 通常の果物 | 加点 | なし |
| 虫 | 減点 | なし |
| バナナ | 加点 | 皮を地面へ投げる |
| 唐辛子 | 加点 | 一定時間、追従速度の上昇と左右の自動揺れ |
| フィーバー果物 | 加点 | 取得時から本編終了まで、果物の生成頻度と追従速度が上がり、弾き上げ範囲でも取得できる |

## バナナの皮

食べた瞬間の下側キャラクターと反対側へ投げ、画面左右の所定位置に着地させる。中央時も配置側を先に確定する。

着地した皮を踏むと、その皮がある側の壁へ滑走する。移動中の速度や向きは判定に使わない。壁到達時に一度だけ画面を揺らし、果物をまとめて追加生成して滑走を終える。皮は使用後に消す。

バナナまたは皮が画面上にある間は、新しいバナナを生成しない。

## 一時効果と移動

移動は「バナナ滑走 ＞ 唐辛子補正 ＞ 通常追従」の順で優先する。滑走中は顔追従と自動揺れを止め、終了時に唐辛子の効果時間が残っていれば復帰する。唐辛子中も顔による誘導は有効。

唐辛子の再発動は残り時間を更新し、重複加算しない。フィーバーは取得時から本編終了まで続く。唐辛子とフィーバーは併存できる。バナナの追加生成はフィーバーとは別の一回限りのイベントとする。

フィーバー中は移動速度の上限を通常の1.5倍にし、追従の応答時間を1/1.5に短縮する。顔・マウスによる追従とキーボード移動に適用し、唐辛子の速度倍率とは乗算する。バナナ滑走の速度は変えない。倍率はCharacterPairControllerの`Fever Speed Multiplier`で調整する。

フィーバー中はEaterの縦横を通常の1.2倍にし、声量による横幅の変化に重ねる。口と左右の救済用判定も一緒に拡大する。Carrierは移動中の足踏みを1.5倍速（通常6コマ/秒 → 9コマ/秒）にし、停止中は通常どおり正面を向く。フィーバー終了時に倍率を解除し、本編終了でEaterを無効にすると初期サイズへ戻す。

拡大倍率はEaterの`Fever Scale Multiplier`、足踏み速度はCarrierAnimatorの`Fever Walk Speed Multiplier`で調整する。どちらも`Falling Item Spawner`に本編のSpawnerを設定する。

出現時刻・頻度・共通上限はFallingItemSpawner、唐辛子・滑走の強さはCharacterPairController、皮の投擲・追加落下・画面揺れはItemEffectControllerのInspectorで調整する。50秒間の流れと、フィーバー果物の再出現は[SpawnDesign.md](SpawnDesign.md)を参照。

種類・得点は`Assets/Data/Items`、最大開口倍率・弾き上げ初速はEaterのInspectorで調整する。救済用判定の位置と大きさはEaterの子にある`LeftBounceSensor`／`RightBounceSensor`で調整する。操作は[Controls.md](Controls.md)を参照。
