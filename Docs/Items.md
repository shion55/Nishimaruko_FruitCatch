# アイテム仕様

アイテムの定義、取得ルール、追加メカニクスと検証方法をまとめます。操作方法は[操作ガイド](Controls.md)を参照してください。

## アイテム共通基盤（フェーズ2）

種類・得点・判定幅は`Assets/Data/Items`の定義アセットで管理し、各Prefabの`CatchableItem`から参照します。食後効果と得点集計の区分は種類から決まり、虫には食後効果を付けません。

| 種類 | 定義アセット | 得点 | 食後効果 |
| --- | --- | --- | --- |
| 通常の果物 | `Fruit.asset` | +10 | なし |
| 虫 | `Bug.asset` | -5 | なし |
| フィーバー果物 | `FeverFruit.asset` | +10 | 8秒間のフィーバー |

`Local Catch Width`は拡大縮小前の判定幅です。現在は既存Colliderの横幅を設定しており、生成後の横スケールを掛けた値を使います。口の幅との比較と反射はフェーズ3で追加します。バナナ・唐辛子の種類は定義できますが、出現と個別効果は後続フェーズで追加します。

取得は口が開いている場合だけ成功し、同じアイテムの得点・演出・効果・取得通知を一度だけ処理します。フィーバーの再発動は残り時間を8秒に更新し、時間を加算しません。ゲーム終了などで生成を停止するとフィーバーも解除します。

実機入力なしの基盤確認は、MainGameを再生し、マウスデバッグをOFFにして次のコマンドをプロジェクトのルートから実行できます。検証用オブジェクトだけを作成・削除し、実プレイの得点は変更しません。

```sh
unity command script run --caller plugin --skill unity-pipeline --file Tools/Verification/ItemFoundationVerification.cs --entry ItemFoundationVerification.Run
```
