# 落下物の仕様

## 取得と反射

- 口が開き、果物の幅が口幅以下なら取得する。閉口時は取得・反射しない。
- 大きすぎる果物は消費せず、当たった側の斜め上へ反射する。中央では真上、左右端では鉛直から最大45°。
- 上昇中は音程による減速と再取得を行わない。下降すると通常の音程制御へ戻り、再取得できる。
- 左右の画面端では横速度を止め、その位置で下降する。
- 虫は大きさによる反射を行わず、取得時に減点だけを行う。

Eaterの口判定は横向きカプセル。声量で横幅だけを変え、高さは固定する。得点と食後効果は取得時に一度だけ発生する。

## 種類

| 落下物 | 得点 | 食後の効果 |
| --- | --- | --- |
| 通常の果物 | +10 | なし |
| 虫 | -5 | なし |
| バナナ | +10 | 皮を地面へ投げる |
| 唐辛子 | +10 | 一定時間、追従速度の上昇と左右の自動揺れ |
| フィーバー果物 | +10 | 一定時間、果物の生成頻度が上がる |

## バナナの皮

食べた瞬間の下側キャラクターと反対側へ投げ、画面幅の35%または65%付近に着地させる。中央時も配置側を先に確定する。

着地した皮を踏むと、その皮がある側の壁へ滑走する。移動中の速度や向きは判定に使わない。壁到達時に一度だけ画面を揺らし、果物をまとめて追加生成して滑走を終える。皮は使用後に消す。

バナナまたは皮が画面上にある間は、新しいバナナを生成しない。

## 一時効果と移動

移動は「バナナ滑走 ＞ 唐辛子補正 ＞ 通常追従」の順で優先する。滑走中は顔追従と自動揺れを止め、終了時に唐辛子の効果時間が残っていれば復帰する。唐辛子中も顔による誘導は有効。

同じ効果の再発動は残り時間を更新し、重複加算しない。唐辛子とフィーバーは併存できる。バナナの追加生成はフィーバーとは別の一回限りのイベントとする。

## 現在の調整値

| 項目 | 値 |
| --- | --- |
| 口の幅・高さ | 幅0.6～0.9、高さ0.2 |
| 開口の声量 | Gain 0.1超で開口、0.25で最大 |
| 通常果物の幅 | 1.68 |
| 基準下降速度 | 2～4 units/秒。高音ほど遅い |
| 反射 | 初速5 units/秒、上昇時の重力10 units/秒² |
| フィーバー | 8秒間、0.2秒ごとに果物2個 |

種類・得点・判定幅は`Assets/Data/Items`、反射角・初速はEaterのInspectorで調整する。操作は[Controls.md](Controls.md)を参照。
