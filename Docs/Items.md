# 落下物の仕様

## 取得と弾き上げ

- 口が開いている間は、落下物の幅に関係なく口への接触で取得する。閉口時は取得・弾き上げを行わない。
- 口の左右のさらに外側に救済用の判定を置く。口には触れず、この判定だけに触れた果物を消費せず真上へ弾き上げる。
- 口と救済用の判定へ同時に触れた場合は取得を優先する。
- 弾き上げは果物1個につき何回でも行う。上昇中は再び弾かず、下降後に外側へ触れると弾き直す。
- 上昇中も口へ触れれば取得できる。音程による減速は上昇中には適用せず、下降すると通常の音程制御へ戻る。
- 弾き上げによる横移動はない。画面下へ落ちた落下物は削除する。
- 虫は口への接触で減点だけを行い、外側の救済用判定では取得・弾き上げを行わない。

Eaterの口判定は横向きカプセル。声量で横幅だけを変え、高さは固定する。左右の救済用判定は口より下に置き、開口に合わせて外側へ広がる。声量による口幅の変化は、取得できる横方向の範囲に影響する。得点と食後効果は取得時に一度だけ発生する。

## 種類

| 落下物 | 得点 | 食後の効果 |
| --- | --- | --- |
| 通常の果物 | 加点 | なし |
| 虫 | 減点 | なし |
| バナナ | 加点 | 皮を地面へ投げる |
| 唐辛子 | 加点 | 一定時間、追従速度の上昇と左右の自動揺れ |
| フィーバー果物 | 加点 | 一定時間、果物の生成頻度が上がる |

## バナナの皮

食べた瞬間の下側キャラクターと反対側へ投げ、画面左右の所定位置に着地させる。中央時も配置側を先に確定する。

着地した皮を踏むと、その皮がある側の壁へ滑走する。移動中の速度や向きは判定に使わない。壁到達時に一度だけ画面を揺らし、果物をまとめて追加生成して滑走を終える。皮は使用後に消す。

バナナまたは皮が画面上にある間は、新しいバナナを生成しない。

## 一時効果と移動

移動は「バナナ滑走 ＞ 唐辛子補正 ＞ 通常追従」の順で優先する。滑走中は顔追従と自動揺れを止め、終了時に唐辛子の効果時間が残っていれば復帰する。唐辛子中も顔による誘導は有効。

同じ効果の再発動は残り時間を更新し、重複加算しない。唐辛子とフィーバーは併存できる。バナナの追加生成はフィーバーとは別の一回限りのイベントとする。

種類・得点は`Assets/Data/Items`、最大開口倍率・弾き上げ初速はEaterのInspectorで調整する。救済用判定の位置と大きさはEaterの子にある`LeftBounceSensor`／`RightBounceSensor`で調整する。操作は[Controls.md](Controls.md)を参照。
