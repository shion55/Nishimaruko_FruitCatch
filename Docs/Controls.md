# 操作ガイド

FruitCatchの通常操作と、カメラ判定・マイク入力を代替するデバッグ操作をまとめます。

## 通常操作

2人で「顔を動かす人」と「声を出す人」を分担します。

| 入力 | 動作 |
| --- | --- |
| 顔を左右へ動かす | 顔位置を移動目標にし、Carrierが遅れて追従してEaterを運ぶ |
| マイクに向かって声を出す | Eaterが口を開き、触れた落下物を取る |
| 声の高さを変える | 果物と虫の落下速度が変わる |

Preparationで両手を上げて開始し、役割説明、顔登録、声の確認、アイテム説明、カウントダウンを経てMainGameへ進みます。本編は50秒間で、結果を10秒間表示した後にPreparationへ戻ります。

顔位置とマウス位置への追従は、`CharactorParent`の`CharacterPairController`で共通に制御します。`Move Speed`は移動速度の上限（初期値5 units/秒）、`Follow Smooth Time`は追従の滑らかさ（初期値0.2秒）です。`Follow Smooth Time`を大きくすると、目標への反応が緩やかになります。一定時間待ってから動き出す入力遅延ではありません。顔が検出されなくなった場合は、`FaceMovementController`の`Tracking Timeout`（初期値0.5秒）を過ぎると停止します。

画面下部の黄色い上向き三角形は、顔・マウスによる移動目標を示します。三角形は入力位置へすぐに移動し、キャラクターが遅れて追従します。有効な入力がない場合は三角形を非表示にします。

## デバッグ操作の準備

- Editorでは再生中のGameビュー、Development Buildではゲームウィンドウにフォーカスして操作します。
- `F2`でマウスデバッグのON/OFFを切り替えます。通常のリリースビルドでは無効です。
- Play開始時はOFFです。シーンを移動してもON/OFFの状態を引き継ぎ、再生を終了して開始し直すとOFFへ戻ります。
- マウス操作はゲームの表示範囲内で行います。ウィンドウがフォーカスを失っている間はマウス操作を受け付けません。

## 準備画面：Preparation

`PreparationFlowController`の`developmentMode`が有効な場合に使用できます。マウスで操作する場合は、さらに`F2`でマウスデバッグをONにします。

| キー／マウス操作 | 動作 |
| --- | --- |
| `Space`／左クリック | 検知条件を待たず、次の説明へ進む。最後の説明ではカウントダウンを開始する |
| `Backspace`／右クリック | 前の説明へ戻る。先頭では何もしない |
| `R` | 準備画面の説明を最初からやり直す |
| `C` | カメラ利用可能／不可の模擬表示を切り替える |

進む・戻る・最初からの操作は、フェードやカウントダウンの途中では受け付けません。押し続けても連続では進まないため、1回ずつ押してください。

`C`は表示を切り替える機能で、顔登録や検知の成功を模擬する機能ではありません。検知条件を飛ばす場合は`Space`または左クリックを使います。`R`は画面の進行を先頭へ戻す操作で、Python側の顔登録を解除する操作ではありません。

操作説明のオーバーレイは`showDebugOverlay`で表示を切り替えられます。非表示でも、`developmentMode`が有効ならデバッグ操作は使えます。

## ゲーム本編：MainGame

### マウスデバッグON

| マウス操作 | 動作 |
| --- | --- |
| 左右へ動かす | マウスの横位置を移動目標にし、キャラクターが遅れて追従する。画面端では移動範囲に制限される |
| 左ボタンを押している間 | 口を開き、触れた落下物を取る。離すと口を閉じる |
| 右ボタンを押している間 | 果物と虫の落下を低速化する。離すと徐々に通常速度へ戻る |
| 左右のボタンを同時に押す | 落下を低速にしながら口を開いて取る |

マウスデバッグ中は、顔位置・マイク音量・音程による本編の操作を無視します。Pythonやマイク処理自体を停止する機能ではありません。

マウスがGameビューの表示範囲から外れた場合や、ウィンドウがフォーカスを失った場合は移動を停止します。`F2`で入力を切り替えた際も、現在位置から新しい目標へ追従し、瞬間移動はしません。

### マウスデバッグOFF

通常の顔・マイク入力へ戻ります。キーボードでは次の移動操作も使えます。

| キー | 動作 |
| --- | --- |
| `A`／`←` | 左へ移動する |
| `D`／`→` | 右へ移動する |

移動キーを押している間はキーボード移動を優先し、キーを離すと顔位置への追従へ戻ります。キーボードだけで確認する場合は、`FaceMovementController`の`movefacetoggle`をONにして顔移動を止めます。

口の開閉や声の高さを模擬するキーボード操作はありません。実機入力なしで取得や低速化を確認する場合は、マウスデバッグを使用してください。

## 実機入力なしで確認する手順

1. `Assets/Scenes/Preparation.unity`を開いて再生します。
2. Gameビューにフォーカスし、`F2`を1回押してマウスデバッグをONにします。
3. 左クリックで説明を進めます。最後の説明からはカウントダウン後に本編へ移動します。
4. マウスを左右へ動かし、左ボタンを押して落下物を取ります。
5. 右ボタンを押して低速化を確認します。左ボタンとの同時押しも使用できます。
6. 通常入力を確認するときは、もう一度`F2`を押してOFFにします。

### 追従移動の確認

1. MainGameの再生中、`F2`でマウスデバッグをONにします。
2. マウスを左右へ大きく動かし、キャラクターが瞬間移動せず、遅れて追い付くことを確認します。
   画面下部の三角形は先に移動し、キャラクターがその横位置へ追従します。
3. マウスを止め、目標位置へ滑らかに収束することを確認します。
4. 左右の端へ誘導し、移動範囲から出ないことを確認します。
5. マウスをGameビューの外へ出し、キャラクターが停止することを確認します。
6. `F2`でOFFにし、顔追従とキー移動を確認します。顔追従にはPython側からの位置送信が必要です。
7. 顔追従中に移動キーを押し、押している間だけキーボードが優先され、離すと現在位置から顔追従へ戻ることを確認します。

アイテムの種類・取得ルール・効果・検証方法は、[アイテム仕様](Items.md)を参照してください。

## マイク設定パネルについて

`MicrophoneDebugUI`には`F1`で設定・計測パネルを表示／非表示にする処理があります。ただし、現在のMainGameではこのコンポーネント自体が非アクティブな`DebugPanel`に付いており、非表示状態から`F1`で開けない構成です。デバッグ用の移動・取得操作には使用しません。
