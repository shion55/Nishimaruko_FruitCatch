# 操作ガイド

FruitCatchの通常操作と、カメラ判定・マイク入力を代替するデバッグ操作をまとめます。

## 通常操作

2人で「体を動かす人」と「声を出す人」を分担します。既定の骨格追跡では両肩の中心を使います。ランチャーで顔追跡を選んだ場合は顔の横位置を使います。

カメラに映るのは顔を動かす1人だけです。声の担当はカメラの撮影範囲外に立ちます。追加のマーカーは使用しません。

カメラに映るのは顔を動かす1人だけです。声の担当はカメラの撮影範囲外に立ちます。追加のマーカーは使用しません。

| 入力 | 動作 |
| --- | --- |
| 顔を左右へ動かす | 顔位置を移動目標にし、Carrierが遅れて追従してEaterを運ぶ |
| マイクに向かって声を出す | Eaterが口を開き、触れた落下物を取る。音量が大きいほど背景の波紋が遠くまで広がる |
| 声の高さを変える | 果物と虫の落下速度が変わり、減速量に応じた波紋が背景に広がる |

Preparationでは両手上げで開始し、役割説明、顔登録と変身、トコミンの左右移動練習、パクッチョの発声、2人で果物を取る練習、アイテム説明、カウントダウンの順に進みます。本編終了後は結果を表示し、Preparationへ戻ります。

顔位置とマウス位置への追従は、`CharactorParent`の`CharacterPairController`で共通に制御します。`Move Speed`は移動速度の上限、`Follow Smooth Time`は追従の滑らかさです。`Follow Smooth Time`を大きくすると、目標への反応が緩やかになります。一定時間待ってから動き出す入力遅延ではありません。顔が検出されなくなった場合は、`FaceMovementController`の`Tracking Timeout`を過ぎると停止します。

画面下部の黄色い上向き三角形は、顔・マウスによる移動目標を示します。三角形は入力位置へすぐに移動し、キャラクターが遅れて追従します。有効な入力がない場合は三角形を非表示にします。

## デバッグ操作の準備

- Editorでは再生中のGameビュー、Development Buildではゲームウィンドウにフォーカスして操作します。
- `F3`でマウスデバッグのON/OFFを切り替えます。通常のリリースビルドでは無効です。
- Play開始時はOFFです。シーンを移動してもON/OFFの状態を引き継ぎ、再生を終了して開始し直すとOFFへ戻ります。
- マウス操作はゲームの表示範囲内で行います。ウィンドウがフォーカスを失っている間はマウス操作を受け付けません。

## 準備画面：Preparation

顔登録では、カメラ映像上の左側の楕円に顔を合わせて3秒間キープします。枠が緑になって進捗がたまり、完了すると楕円内の顔がトコミンへ変わってから左右移動練習へ進みます。背景のカメラ映像の位置・表示範囲は前後の画面と共通です。

登録時に顔の特徴量をメモリ内に保持し、追跡対象が曖昧な場合や再捕捉時に照合します。短い検出途切れ（0.25秒以内）では進捗を一時停止し、それを超える途切れ・枠からの移動・枠内の複数顔検出では最初からになります。処理の遅いPCではキープに3秒以上かかる場合があります。

顔登録ではYuNetで検出した顔とMediaPipe Poseの身体を対応付けます。練習でも本編と同じ横位置を使います。追跡が途切れた場合はカメラの前に戻ってください。練習では途切れが続くと「顔を あわせ直す」が表示され、変身後に元の練習に戻れます。

移動練習では左右の目印を両方取り、果物練習では果物の下に移動して声を出します。果物を逃すと次の果物が出ます。練習中の取得は本編の得点やランキングに反映されません。

変身時間は`FaceAlignmentArea_Replaceable`の`PreparationFacePresentation`にある`Morph Duration`（初期値1.5秒）、変身後の待機は`Carrier Hold Seconds`（初期値1秒）で調整します。楕円の位置・大きさは同オブジェクトのRectTransformで調整し、再生時にPythonの判定へ反映します。Pythonの変更後は、起動中のトラッカーを再起動してください。

変身開始時には説明パネルでカメラの顔を隠し、切り出した顔が縮んで光と星に包まれ、Carrierが跳ねて着地します。変身後も顔が透けないようパネルを不透明に保ちます。戻って顔を登録し直す場合は、楕円の切り抜きを復元します。カメラ映像そのものの位置・表示範囲・配信は変更しません。

声の確認では、声に応じてパクッチョが口を開いて弾み、下のメーターが動きます。線を超える音量を約0.8秒続けると○が表示され、2.5秒後に次へ進みます。検出しきい値は`PreparationVoiceDetector`の`Gain Threshold`（0.015）、短い途切れの猶予は`Release Grace Seconds`（0.2秒）です。使用するマイクは保存済みの本編設定を引き継ぎます。

Inspectorでは`PreparationFlowController`の各ステップの時間、`PreparationPractice`の目標許容幅・移動距離・落下時間・再出現時間・追跡復帰案内までの猶予を調整できます。左右の目標と果物の開始位置は各RectTransformで調整します。発声のリアクションとBGMの音量・フェードは`PreparationVoiceDetector`、練習の成功SEは`FruitCatchAudioSettings`にあります。

`PreparationFlowController`の`developmentMode`が有効な場合に使用できます。マウスで操作する場合は、さらに`F3`でマウスデバッグをONにします。

| キー／マウス操作 | 動作 |
| --- | --- |
| `Space`／左クリック | 検知条件を待たず、次の説明へ進む。最後の説明ではカウントダウンを開始する |
| `Backspace`／右クリック | 前の説明へ戻る。先頭では何もしない |
| `R` | 準備画面の説明を最初からやり直す |
| `C` | カメラ利用可能／不可の模擬表示を切り替える |

移動練習では `F3` でマウス移動を使えます。発声と果物の練習では左ボタン長押しで声を模擬します。練習の条件を飛ばすには `Space` を使います。

進む・戻る・最初からの操作は、フェードやカウントダウンの途中では受け付けません。押し続けても連続では進まないため、1回ずつ押してください。

`C`は表示を切り替える機能で、顔登録や検知の成功を模擬する機能ではありません。検知条件を飛ばす場合は`Space`または左クリックを使います。`R`は画面の進行を先頭へ戻す操作で、Python側の顔登録を解除する操作ではありません。

操作説明のオーバーレイは`showDebugOverlay`で表示を切り替えられます。非表示でも、`developmentMode`が有効ならデバッグ操作は使えます。

## ゲーム本編：MainGame

### マウスデバッグON

| マウス操作 | 動作 |
| --- | --- |
| 左右へ動かす | マウスの横位置を移動目標にし、キャラクターが遅れて追従する。画面端では移動範囲に制限される |
| 左ボタンを押している間 | 口を開き、触れた落下物を取る。離すと口を閉じる |
| 左ボタンを押しながらホイール上下 | 上で開口量（模擬音量）を増やし、下で減らす。右ボタンも押すと波紋の範囲も変わる。再生開始時は最大開口 |
| 右ボタンを押して上下へ動かす | 画面下端を低音、上端を高音として音程を模擬する。現在の設定では上ほど落下が遅く、背景の波紋が強くなる。離すと放出が止まり、徐々に通常速度へ戻る |
| 左右のボタンを同時に押す | 口を開いて取りながら、マウスの上下で音程を変える |

マウスデバッグ中は、顔位置・マイク音量・音程による本編の操作を無視します。Pythonやマイク処理自体を停止する機能ではありません。

右ボタンによる模擬音程は、下端から上端までを`PitchFallSpeedController`の`Min Pitch Hz`〜`Max Pitch Hz`に相当する0〜1へ対応させます。中央は範囲の中間で、音程と減速量の対応・平滑化は実際のマイク入力と共通です。右ボタンを押している間は低音でも弱い波紋が出ます。表示範囲外・フォーカス喪失時は模擬音程を無効にします。

マウスがGameビューの表示範囲から外れた場合や、ウィンドウがフォーカスを失った場合は移動を停止します。`F3`で入力を切り替えた際も、現在位置から新しい目標へ追従し、瞬間移動はしません。

### マウスデバッグOFF

通常の顔・マイク入力へ戻ります。キーボードでは次の移動操作も使えます。

| キー | 動作 |
| --- | --- |
| `A`／`←` | 左へ移動する |
| `D`／`→` | 右へ移動する |

移動キーを押している間はキーボード移動を優先し、キーを離すと顔位置への追従へ戻ります。キーボードだけで確認する場合は、`FaceMovementController`の`movefacetoggle`をONにして顔移動を止めます。

口の開閉や声の高さを模擬するキーボード操作はありません。実機入力なしで取得や低速化を確認する場合は、マウスデバッグを使用してください。

## 展示運営

- `F1` 準備画面へ戻り、再登録します。
- `F2` 登録を維持して本編を最初から始めます。
- `Esc` 配布版のUnityを終了し、ランチャーへ戻ります。

## Windowsで顔追跡の修正を確認する

1. 起動中のゲームとPythonトラッカーを終了し、修正を含む配布版の`Start FruitCatch.bat`で起動します。初回は`Setup FruitCatch.bat`を実行します。
2. 操作担当がカメラの前に立ち、両手上げ、3秒の位置合わせ、左右移動、発声、果物練習を経て本編へ進みます。
3. 頭を左右へ動かし、黄色い三角形が顔の横位置へ追従し、キャラクターが従来どおり遅れて付いてくることを確認します。
4. 一度撮影範囲の外へ出て停止を確認し、戻ると再登録なしで操作が復帰することを確認します。
5. 結果画面からPreparationへ戻り、再び両手上げと位置合わせが使えることを確認します。

撮影の初期設定は`Tools/camera_config.json`（配布版は`Tracking/camera_config.json`）の1280×720・30fps要求です。カメラの対応モードにより実際の解像度・FPSは異なります。重い場合は`use_max_resolution`を`false`のまま、`width`を640、`height`を480に下げて比較してください。設定変更後はトラッカーを再起動します。

撮影・推論・JPEG圧縮は別々に動作し、推論とプレビューには最新の撮影フレームを使います。本編では登録した対象の追跡が続きます。

## 実機入力なしで確認する手順

1. `Assets/Scenes/Preparation.unity`を開いて再生します。
2. Gameビューにフォーカスし、`F3`を1回押してマウスデバッグをONにします。
3. 左クリックで説明を進めます。最後の説明からはカウントダウン後に本編へ移動します。
4. マウスを左右へ動かし、左ボタンを押して落下物を取ります。
5. 右ボタンを押したまま上下へ動かし、上ほど落下が遅く、波紋が強くなることを確認します。左ボタンとの同時押しも使用できます。
6. 通常入力を確認するときは、もう一度`F3`を押してOFFにします。

### 追従移動の確認

1. MainGameの再生中、`F3`でマウスデバッグをONにします。
2. マウスを左右へ大きく動かし、キャラクターが瞬間移動せず、遅れて追い付くことを確認します。
   画面下部の三角形は先に移動し、キャラクターがその横位置へ追従します。
3. マウスを止め、目標位置へ滑らかに収束することを確認します。
4. 左右の端へ誘導し、移動範囲から出ないことを確認します。
5. マウスをGameビューの外へ出し、キャラクターが停止することを確認します。
6. `F3`でOFFにし、顔追従とキー移動を確認します。顔追従にはPython側からの位置送信が必要です。
7. 顔追従中に移動キーを押し、押している間だけキーボードが優先され、離すと現在位置から顔追従へ戻ることを確認します。

アイテムの種類・取得ルール・効果は、[アイテム仕様](Items.md)を参照してください。

## マイク設定パネルについて

`MicrophoneDebugUI`には`F1`で設定・計測パネルを表示／非表示にする処理があります。ただし、現在のMainGameではこのコンポーネント自体が非アクティブな`DebugPanel`に付いており、非表示状態から`F1`で開けない構成です。デバッグ用の移動・取得操作には使用しません。

## 声の高さによる背景の波紋

MainGameでは、有効な音程が検出されている間、Eaterの口元から背景に円形の波紋を出します。現在の設定では、高い声ほど落下の減速が強まり、波紋の歪み・明るさ・発生頻度が増します。声が大きいほど、同じ寿命の間に波紋が速く・遠くまで広がります。背景だけを歪ませ、キャラクター・落下物・UIには影響しません。

音量による到達半径は、従来の波紋を最小の1倍とし、最大音量で3倍になります。輪の幅・寿命は変えません。音量は口の拡縮と同じ入力・平滑化・`Max Gain`（現在0.25）を共有します。デバッグ中は右ボタンだけで最小サイズ、左右同時押しで音量を模擬し、左ボタンを押したままホイールで音量を変えられます。

各波紋は、発生時のワールド座標・強さ・半径倍率を保持します。キャラクターの移動や音量の変化で古い波紋が引っ張られたり急に拡大したりせず、移動先から新しい波紋が出ます。音程の検出が途切れても落下速度制御と共通の保持時間（現在0.2秒）だけ入力を保持し、その後は放出を止めます。残った波紋は寿命（現在0.75秒）で消えます。開始前・結果画面では波紋を消去します。

### 調整箇所

- 背景の`VoiceRippleBackground`：`Lifetime`は寿命、`Wave Speed`は広がる速さ、`Wave Width`は輪の幅、`Distortion`は歪みの強さ（ワールド単位）、`Ring Color`のAlphaは輪の明るさです。
- `Max Radius Multiplier`は最大音量での半径倍率（初期値3）です。1にすると従来と同じ範囲になります。`Voice Controller`は音量を参照するEaterです。
- `Low Pitch Interval`／`High Pitch Interval`は弱い減速／強い減速での発生間隔、`Minimum Strength`は有声音程を検出したときの最小の強さです。通常速度に近い声でも弱い波紋を表示します。
- Eaterの子`VoiceRippleOrigin`：波紋の発生点です。初期位置は口のColliderの中心に合わせています。
- `PitchFallSpeedController`：音程範囲・保持時間・平滑化を落下速度と共有します。現シーンの音程範囲は90〜259Hzです。波紋の強さは適用済みの減速量を使うため、`High Pitch Faster`をONにすると低い声ほど強くなります。

背景は専用マテリアル`VoiceRippleBackground`を使います。現在の1枚背景を対象としており、背景をSprite Atlasへ入れる場合は回転パッキングを無効にしてください。同時に保持する波紋は最大8個です。

### マイクなしでの確認

1. MainGameを再生し、スタート表示が終わったら`F3`でマウスデバッグをONにします。
2. Gameビュー内で右ボタンを押したまま下→中央→上へ動かし、落下が徐々に遅くなり、波紋が強く・密になることを確認します。左ボタンを押す必要はありません。
3. 右ボタンを押したまま左右へ動かし、古い波紋が元の発生位置に残ることを確認します。
4. 右ボタンを離し、放出が止まって残った波紋が消えることを確認します。
5. `F3`でOFFにしてマイク入力に戻し、低い声・高い声・無声で比較します。

音量による範囲は、右ボタンだけの最小サイズと、左右同時押しの大きいサイズを比較します。左右同時押しのままホイールを下げると音量・範囲が小さくなり、上げると大きくなります。マウスの上下位置を固定すると、音程を変えずに音量だけを比較できます。
