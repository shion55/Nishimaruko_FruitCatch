# 開発引き継ぎ

更新：2026-11-22。仕様は[Items.md](Items.md)、操作は[Controls.md](Controls.md)。

## 現状

- ブランチは`develop`。開始時に現在の差分と履歴を確認する。機能ごとのブランチ作成は不要。
- 大きさ判定・反射と横向きカプセルを実装済み。利用者によるカプセル・文書の調整までコミット済み。
- 顔・マウス位置への遅れ追従、目標位置の三角形、虫の減点、フィーバーは実装済み。キャラクター親の高さは利用者調整のY=0.4を維持。
- 果物の幅に応じた取得・反射、上昇中の音程除外、下降後の再取得、画面端処理は実装済み。Eaterは横向きカプセルで横幅だけ拡大し、高さ0.2を固定。
- 共通処理8項目とカプセル・反射9項目はAI側で確認済み。その後の利用者調整は保持している。

## 残作業

現在の最大口幅0.9は通常果物幅1.68より小さく、通常果物を取得できない。次の作業で開口倍率または果物幅の調整を確認する。

1. 唐辛子：独立した効果タイマー、追従速度上昇、自動揺れ。通常入力への誘導を維持する。
2. バナナ：反対側への投擲、着地・踏み判定、壁への滑走、画面揺れ、一度きりの追加生成。バナナ・皮がある間の生成抑止も必要。
3. 一時効果の併存・優先順位、終了時の停止と片付けを統合確認する。
4. バナナ・唐辛子の素材とPrefabを追加し、Preparationの説明を更新する。Windows実機で顔・マイク入力も確認する。

## 実装の入口

- `CharacterPairController`：移動を一元管理。`FaceMovementController`は目標入力のみ。
- `ItemDefinition`／`CatchableItem`：種類・得点・幅と一度だけの消費。`EaterCatchController`が取得結果と食後効果を処理する。
- `FallingObject`：Kinematic Rigidbody2Dの固定更新で下降・反射を制御。`FallingItemSpawner`：通常生成とフィーバー。
- `TemporaryEffectTimer`：再発動で残り時間を更新。唐辛子にも再利用する。
- `FruitCatchGameSession`：本編50秒、結果表示後にPreparationへ戻る。追加効果の停止もここへ接続する。

## 作業時の注意

- Unity `6000.6.4f1`。CLIは`--project-path`で本プロジェクトを指定し、必要な操作だけ権限付きで実行する。UnityやPackageは更新しない。
- AI側の検証コードは`Tools/Verification`。カプセルの縦幅固定と既存の取得・反射を再生中に確認する。利用者へはGameビューでの確認を案内する。
- 実行時に生じたフォント・Unity設定などの差分も内容を確認し、問題がなければコミットに含める。
- 文書に工程番号や自動確認コマンドを書かない。仕様はItems、操作はControls、進捗は本書へ分けて簡潔に更新する。
