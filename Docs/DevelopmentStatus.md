# 開発引き継ぎ

更新：2026-11-22。仕様は[Items.md](Items.md)、操作は[Controls.md](Controls.md)。

## 現状

- ブランチは`develop`。開始時に現在の差分と履歴を確認する。機能ごとのブランチ作成は不要。
- 口への接触取得と、口の外側にある左右の救済用コライダーを実装済み。果物の幅による取得制限は廃止。
- 顔・マウス位置への遅れ追従、目標位置の三角形、虫の減点、フィーバーは実装済み。キャラクター親の高さは利用者調整を維持。
- 救済では果物を真上へ何回でも弾き上げ、口との同時接触は取得を優先する。上昇中の音程除外と、接触時の取得に対応。
- 表示は元の閉口・開口の一枚絵切り替えへ戻し、最大口幅も分割前の設定へ戻した。Eaterは横向きカプセルで横幅だけ拡大し、高さを固定。
- 斜め反射・横移動・左右端補正・判定幅データを削除。生成時の表示範囲内への配置と、画面下へ落ちた落下物の削除は残している。
- 接触取得・救済12項目と共通処理8項目はAI側で確認済み。左右とも同じ果物を3回弾いた後の再取得を確認している。

## 残作業

口への接触取得と救済用判定の広さ・弾き上げ高さについて、Gameビューで遊びやすさを確認する。

1. 唐辛子：独立した効果タイマー、追従速度上昇、自動揺れ。通常入力への誘導を維持する。
2. バナナ：反対側への投擲、着地・踏み判定、壁への滑走、画面揺れ、一度きりの追加生成。バナナ・皮がある間の生成抑止も必要。
3. 一時効果の併存・優先順位、終了時の停止と片付けを統合確認する。
4. バナナ・唐辛子の素材とPrefabを追加し、Preparationの説明を更新する。Windows実機で顔・マイク入力も確認する。

## 実装の入口

- `CharacterPairController`：移動を一元管理。`FaceMovementController`は目標入力のみ。
- `ItemDefinition`／`CatchableItem`：種類・得点・食後効果と一度だけの消費。`EaterCatchController`が口を先に判定し、外側の救済・取得結果・食後効果を処理する。
- `FallingObject`：Kinematic Rigidbody2Dの固定更新で下降・垂直弾き上げを制御。`FallingItemSpawner`：通常生成とフィーバー。
- `TemporaryEffectTimer`：再発動で残り時間を更新。唐辛子にも再利用する。
- `FruitCatchGameSession`：本編と結果表示、Preparationへ戻る進行を管理。追加効果の停止もここへ接続する。

## 作業時の注意

- Unity `6000.6.4f1`。CLIは`--project-path`で本プロジェクトを指定し、必要な操作だけ権限付きで実行する。UnityやPackageは更新しない。
- AI側の検証コードは`Tools/Verification`。カプセルの縦幅固定、接触取得、左右の繰り返し弾き上げと再取得を再生中に確認する。利用者へはGameビューでの確認を案内する。
- 実行時に生じたフォント・Unity設定などの差分も内容を確認し、問題がなければコミットに含める。
- 調整値は文書に列挙せず、実装箇所に調整対象や単位の短いコメントを付ける。実際の値はシーン・PrefabのInspectorやアイテム定義で管理する。
- 文書に工程番号や自動確認コマンドを書かない。仕様はItems、操作はControls、進捗は本書へ分けて簡潔に更新する。
