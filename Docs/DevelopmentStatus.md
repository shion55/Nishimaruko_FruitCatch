# 開発引き継ぎ

更新：2026-11-22。仕様は[Items.md](Items.md)、出現設計は[SpawnDesign.md](SpawnDesign.md)、操作は[Controls.md](Controls.md)。

## 現状

- ブランチは`develop`。開始時に現在の差分と履歴を確認する。機能ごとのブランチ作成は不要。
- 口への接触取得と、口の外側にある左右の救済用コライダーを実装済み。
- 顔・マウス位置への遅れ追従、目標位置の三角形、虫の減点、フィーバーは実装済み。キャラクター親の高さは利用者調整を維持。
- 救済では果物を真上へ何回でも弾き上げ、口との同時接触は取得を優先する。上昇中の音程除外と、接触時の取得に対応。
- 表示は閉口・開口の一枚絵切り替え。Eaterは横向きカプセルで横幅だけ拡大し、高さを固定。
- 落下物は表示範囲内へ生成し、画面下へ落ちたら削除する。
- 本編の時計を共有し、50秒のフェーズ別頻度・配置・特殊枠・共通上限を実装済み。通常果物はリンゴ・イチゴ・ブドウから生成する。
- フィーバー果物は取得まで1個ずつ再出現し、取得時から本編終了までフィーバーになる。
- 唐辛子の独立タイマー・追従速度上昇・自動揺れ、バナナの投擲・着地・踏み判定・皮側の壁への滑走・一度だけの追加落下と画面揺れを実装済み。終了時は落下物・皮・効果を片付ける。
- 出現フロー9項目、接触取得・救済16項目、共通処理8項目をAI側で確認済み。出現枠は40通りの乱数、特殊効果は再生中の接触取得で確認している。50秒の通し再生で全フェーズ・未取得時の再出現・終了と結果表示も確認済み。

## 残作業

口への接触取得と救済用判定の広さ・弾き上げ高さについて、Gameビューで遊びやすさを確認する。

- Gameビューで50秒を遊び、フェーズごとの忙しさ、特殊枠の出現数、唐辛子と滑走の強さ、フィーバー果物の取りやすさを確認する。
- Preparationのアイテム説明を更新し、Windows実機で顔・マイク入力を確認する。

## 実装の入口

- `CharacterPairController`：移動を一元管理。`FaceMovementController`は目標入力のみ。
- `ItemDefinition`／`CatchableItem`：種類・得点・食後効果と一度だけの消費。`EaterCatchController`が口を先に判定し、外側の救済・取得結果・食後効果を処理する。
- `FallingObject`：Kinematic Rigidbody2Dの固定更新で下降・垂直弾き上げを制御。`FallingItemSpawner`：時間別の出現枠・共通上限・取得までのフィーバー果物再出現。
- `ItemEffectController`／`BananaPeel`：食後効果、皮の飛行・踏み判定、壁到達時の追加落下・画面揺れ。`TemporaryEffectTimer`は唐辛子の効果時間を管理する。
- `FruitCatchGameSession`：本編の時計、生成と効果の終了、結果表示、Preparationへの復帰を管理する。

## 作業時の注意

- Unity `6000.6.4f1`。CLIは`--project-path`で本プロジェクトを指定し、必要な操作だけ権限付きで実行する。UnityやPackageは更新しない。

- 調整値は文書に列挙せず、実装箇所に調整対象や単位の短いコメントを付ける。実際の値はシーン・PrefabのInspectorやアイテム定義で管理する。
- 文書に工程番号や自動確認コマンドを書かない。仕様はItems、操作はControls、進捗は本書へ分けて簡潔に更新する。
